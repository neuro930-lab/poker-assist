# Poker Assist

テキサスホールデム（キャッシュゲーム）のプリフロップで、ヨコサワ式ハンドレンジ表に沿って「すべきアクション」を表示するPC向けWebアプリです。学習やライブのホームゲームで使うことを想定しています。多くのオンラインポーカーサイトはプレイ中の補助ツールの使用を規約で禁止しているため、オンライン対戦中には使わないでください。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173 を開く
npm test         # 判定ロジックの単体テスト
npm run build    # dist/ に静的ファイルを出力（サーバー不要）
```

1. 「設定」タブで、公式の表を見ながら169ハンドの色と各ポジションの基準色を入力する（レンジ表は著作物なので同梱していません）
2. 「判定」タブで人数を選び、テーブル図で自分の席をクリックする
3. 13×13表で手札をクリックする
4. レイズした人がいれば、その席をクリックする

- 自分の席をもう一度クリックすると選び直せます。右クリックした席が自分の席になります
- `N`：次のハンド（BTNを時計回りに1席進める）、`Esc`：手札・レイズ・状況をリセット
- 設定はブラウザに自動保存されます。JSONの書き出し・読み込みにも対応しています

## 構成

- `src/logic/` …… 判定ロジック（画面から切り離した純粋関数）とテスト
  - `decide.ts`：オープン／vsレイズ／BB／vs3ベット／vs4ベットの判定と想定レンジ
  - `positions.ts`：人数ごとのポジション、座席とポジションの対応、BTNの移動
  - `settings.ts`：設定の型・初期値・検証・保存
- `src/components/` …… テーブル図、13×13表、結果欄、設定画面
