# Poker Assist

テキサスホールデムのゲーム画面（スクリーンショット）をAIで読み取り、**最適なプレー・その理由・ヨコサワハンドレンジ表での位置**を表示する学習用Webアプリです。

多くのオンラインポーカーサイトは、対人戦で補助ツールを使うことを規約で禁止しています。**AI戦での練習・ハンドの振り返り・学習**に使ってください。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173 を開く
npm test         # 判定ロジック・計算エンジンの単体テスト
npm run build    # dist/ に静的ファイルを出力
```

1. 上部で「リングゲーム」か「トーナメント」を選ぶ（ヨコサワ表が切り替わります）
2. スマホの画面をPCにミラーリングする（Android：scrcpy、iPhone：Mac の iPhone ミラーリング など）
3. 「解析」タブ →「リアルタイム（画面共有）」→「画面共有を開始」で、ミラーリングの**ウィンドウ**を選ぶ
4. 画面が変わって落ち着くたびに自動で読み取り、推奨アクション・理由・ヨコサワ表での位置が更新されます（`R` キーで今すぐ読み取り）
5. 「AIコーチに詳しく聞く」で、レンジ・ブロッカー・相手タイプ別の調整・次のストリートの計画まで解説

スクリーンショットを Ctrl+V で貼り付ける方法（「画像を貼り付け」）や、手入力だけでも使えます。

### リアルタイム読み取りの仕組み

- 0.4秒ごとに画面を小さく縮小して前回と比べ、**大きく変わった後に止まったとき**だけAIに送ります（タイマーの動きなど小さな変化は無視）
- 送る間隔の最短（1.5〜8秒）を選べます。読み取り回数は画面に表示されます（1回ごとにAPI料金がかかります）
- 遅いときは「設定」で読み取りモデルを Sonnet / Haiku に変更できます
- 手札が見えないとき（ハンドとハンドの間）は局面を更新しません

### ヨコサワ表（Excel版）

`public/yokosawa-ranges.xlsx`（アプリの「Excel版をダウンロード」）。リング／トーナメントの2シートで、D2 に手札（例：AKo、65s、77）を入れるとそのマスが青くなり、D3 でポジションを選ぶと参加できるか表示します。表のデータを変えたら `python3 scripts/make_yokosawa_xlsx.py` で作り直してください。

画面解析とAIコーチには Anthropic APIキーが必要です（「設定」タブで入力）。キーはブラウザの localStorage にだけ保存され、api.anthropic.com に直接送られます。自分のPCで使う前提の作りです。サーバーに公開する場合は、キーをバックエンド側に置く構成に変えてください。

## 判定の仕組み

| 場面 | 方法 |
| --- | --- |
| プリフロップ（通常） | ヨコサワ表：ハンドの色 ≧ ポジションの基準色ならオープン。レイズに対しては1段上でコール、2段上で3ベット |
| BBのディフェンス | レイザーの基準の1段下までコール。「BBのみコールOK」の段はBTN・SBのレイズに対してだけ。表でフォールドでも、ポジションの不利を割り引いた勝率が必要勝率を上回るならコール（エンジン補正） |
| 3ベット・4ベットされた | 相手の3ベットレンジ（自分の基準＋2段）以上でコール、さらに＋2段で4ベット |
| 有効スタック12BB以下 | オールインかフォールド。相手のコール率とコールされたときの勝率から**チップEV**を計算 |
| フロップ以降 | 相手のレンジ（ヨコサワ表から推定）を、ボードとアクションに合わせて強さ順に重み付けし直し、**モンテカルロで勝率**を計算。ポットオッズ・SPR・ドロー・ボードのテクスチャから、ベット／チェック／コール／レイズ／フォールドとサイズを決める |

ヨコサワ表は、ユーザー提供の画像から `src/logic/yokosawa.ts` に転記しています。設定画面で自分用に調整でき、「ヨコサワ表に戻す」で元に戻せます。

## 構成

- `src/logic/` …… ヨコサワ表のデータ・プリフロップ判定・ポジション・設定
- `src/engine/` …… カード、役判定、勝率計算（モンテカルロ／リバーは厳密）、ドロー・ボード分析、レンジ推定、推奨アクション（`advisor.ts`）
- `src/live/` …… 画面の変化検知（いつAIに読ませるか）
- `src/ai/claude.ts` …… 画面解析（Claude の画像入力＋構造化出力）とAIコーチ（ストリーミング）
- `src/components/` …… 画面（解析タブ・プリフロップ練習・設定）
